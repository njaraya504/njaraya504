## 🎯 What I Do

I coach students in Computer Science, Data Science, Mathematics, Physics, Engineering, and related fields as they figure out where they're headed and how to get there. My focus is helping technical students show what they can do, on paper and online.

- **Resumes** that make technical experience clear to recruiters
- **Technical portfolios** and GitHub profiles that make a strong first impression
- **Interview prep**, especially talking about projects with confidence
- **Career exploration** for students weighing industry, research, and graduate school

## 🛠️ What I'm Building

### [GitHub Portfolio Check](https://njaraya504.github.io/techportfolio-check/)

A free, self-service tool that gives students coaching-style feedback on how their GitHub profile looks to a recruiter. It checks profile setup, READMEs, repository names, and commit history, then suggests specific next steps.
